# Data Analytics

A collection of data analytics projects using Python, pandas and financial datasets.

## Data Analysis with Python

### 01 — Investment Funds Analysis
Exploratory analysis of investment fund data using Python and pandas.

**Skills:** data exploration, filtering, aggregation and visualization.

[View project](01-investment-funds-analysis)

### 02 — Financial Institutions Analysis
Analysis of profitability, business scale and regional differences across a synthetic dataset of European financial institutions.

**Skills:** pandas, filtering, sorting, `groupby()`, `agg()` and descriptive statistics.

[View project](02-financial-institutions-analysis)

### 03 — Investment Portfolio Analysis
Analysis of client portfolios with a focus on asset allocation, geographic and sector exposure, client profiles, recurring holdings and portfolio concentration.

**Skills:** pandas, filtering, `groupby()`, aggregation, portfolio weights, proportions and visualization.

[View project](03-investment-portfolio-analysis)
